## Code facts the design rests on (read this session)

- `crust.rs`: continents = warped distance to "core" arcs + fBm, thresholded so continental crust covers `1.4 × land_fraction`. Gives `cont`, `edge_m` (signed distance to the crust edge), and `activity` (an fBm 0..1 field, independent of plates).
- `plates.rs`: random-place seeds (continent-biased), noisy Dijkstra growth; the only coupling to the coast is a soft cost wall `0.55·activity·bell(edge_m, 140 km)`. Euler poles and rates are **random**; boundary class (convergent/divergent/transform) is read off afterwards. So an active coast is active only if the dice agree.
- `relief.rs`: profiles keyed by distance to boundary nodes of each `Kind` (collision, subduction → trench/cordillera/arc, ridge → GDH1 age-depth, rift). Shelves are rebuilt in `finish` from the coast *after* the sea-level solve, using the same `activity` noise (shelf 120 km passive → 30 km active).
- Sea level: bisection on raw heights to hit `land_fraction`. The coast emerges from heights, not from the crust edge.
- Erosion (`solver.rs:593`): `ocean = h0 ≤ 0`, held as base level; priority-flood keeps land above it. So if the tectonic heights match a mask's sign, erosion keeps the coast (at the erosion grid's resolution).
- World file (schema 4) stores params + committed fields; no user-authored inputs yet.

## Design outline (before the advisor)

1. **Land mask as the stage-0 input.** Procedural (today's crust noise, thresholded to the land fraction) or imported (PNG mask, GeoJSON/SVG polygons) with placement on the sphere; brush edits as resolution-independent strokes. The source and placement are stored in the world file.
2. **Crust from the mask:** continental crust = land plus a margin (wide on passive, narrow on active).
3. **Coast classification:** active/passive per coast segment: automatic (an ocean-facing score plus noise to a target share) with painted overrides.
4. **Plates fitted to the coasts:** boundaries on active coasts (offshore, at trench distance); passive coasts inside plates; mid-ocean ridges on the medial axis between conjugate passive coasts (a multi-source Dijkstra from coasts labelled by landmass: where the fronts meet).
5. **Motions solved, not rolled:** plate angular-velocity vectors from a small linear least-squares problem so that active-coast boundaries converge and ridges diverge (relative velocity across a boundary is linear in the ω vectors). The boundary classification then runs as today on the solved motions.
6. **Coast-conforming heights:** no sea-level bisection in strict mode; land nodes clamped to a small positive coastal ramp and sea nodes rebuilt by `finish`'s shelf/slope profile, so sign(h) = mask. Procedural mode can let arcs and hotspots add islands.
7. Coastal bathymetry from the classification: passive = wide shelf + rise wedge; active = narrow shelf + trench.

## Advisor (before drafting): adopted in full

1. The boundary kind comes from the classification; the ω solve supplies only rate and obliquity. Wrong-sign residuals are clamped and logged.
2. Classify seaways (opening/closing/one-sided), and coasts inherit; minimum segment ~1000 km. This also says where oceanic plates come from.
3. Sutures inside big landmasses, so imported continents still get collision belts.
4. Strict-coast survival is a gate, not a fact (erosion-grid resampling, hypsometric calibration, `ocean = h ≤ 0`). **Unverified.**
5. Phasing: R3.1 science on procedural, R3.2 import, R3.3 brush.
6. The import projection is specified (equirect / azimuthal-equidistant patch).

## Fresh-context review (sonnet-medium, read-only): go with changes, all adopted → design v2

Spot-checked the load-bearing claims in the code myself:
- `uplift.rs` recomputes convergence from poles/omega;
- `grow_regions` has a single global cost;
- `hypsometry.rs:86` `.max(1.0)`;
- `solver.rs:592` bilinear resample then `ocean = h0 ≤ 0`.

Adopted:
1. The motion fit is soft. A rigid rotation's convergence is sinusoidal along a boundary, so long rims can't hold one rate. Gate on the length-weighted RMS residual; wrong-sign share is a diagnostic only. `omega ≥ ε` clamp. **Uplift must read the same clamped rate**: a new committed `convergence_mm_yr` field; otherwise wrong-sign samples get a belt with no uplift.
2. The partition is new code. Land is pre-labelled, ocean comes from a labelled `nearest_source`, and the oceanic plates come from a new `grow_labelled` over unclaimed components (a seed per component, connectivity asserted). Cost walls only delay fronts.
3. Seaway = a connected component of the medial axis, keyed by position. A landmass pair can meet across two oceans. Segment cuts come from position-keyed noise; landmasses are numbered by centroid; components are found at a canonical res 256.
4. Subduction polarity is prescribed by the classification, not a crust-majority vote in a 3-hop ball (a coin toss at res 320, and different across resolutions).
5. Strict coasts: ocean comes from the mask, evaluated on the erosion grid. Hypsometric calibration is safe (land ≥ 1 m), so the coastal ramp is moot. **Unchecked:** lake beds ≤ 0 on mask land.
6. Closing seaways get a prescribed ridge (age needs one). Passive margin width capped at 0.4·D.
7. Phasing: R3.1a (plausibility on procedural, bisection kept) / R3.1b (strict + ocean from the mask). Deferred: escarpments (rift-flank, not random), dormant sutures (merge + old belt instead), SVG, polygon rotation.

- **Refuted:** the initial roughness (cell-scale white noise) and the res-dependent noise-octave count. Neither moves anything.
- **Confirmed, mechanism 1:** stream power uses the raw drainage area, so the smallest catchment is one cell. Finer grids get steeper heads and more interfluve relief everywhere, and the global calibration then scales all land down (peaks included).
  - Floor the area in stream power at a physical channel-head area `A_eff = max(A, A_c)`, with `A_c` ≥ the largest cell. The calibration factor then matches across resolutions (1.211 vs 1.209).
  - Side effect: less relief before calibration, so the factor goes from ~0.7 to 1.2 and the peaks get taller (box max 5.3–5.8 km vs 5.0). It also changes the look (no valleys under A_c).
- **Confirmed, mechanism 2:** lake share grows with resolution (3–15×) and raises the medians. Not yet fixed.
