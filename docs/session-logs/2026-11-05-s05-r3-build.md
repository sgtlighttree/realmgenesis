## R3.1a plan (before code)

Procedural mode: landmasses = **continental-crust** components (the coast emerges later from the bisection, as the design says). New modules:
- `coast.rs`:
  - landmass labels (components of `crust.cont` on a fixed res-128 grid, so isthmuses split the same way at every res; fine nodes inherit through a BFS inside the crust);
  - landmass "regions" over the ocean (noisy multi-source growth from each landmass);
  - medial axis = region borders; seaway = connected axis component per landmass pair; key = quantised axis centroid;
  - `D` = median coast-to-axis distance;
  - class roll (opening / closing / one-sided);
  - segments;
  - per-node `margin`.
- `fit.rs`: continental-plate claims, oceanic plates by `grow_labelled` (new in `grid.rs`, restricted to unclaimed nodes and blocked across closing axes), sutures, prescribed kinds/polarity, the Euler-vector least-squares solve, clamped rates.

Deviations from the design text (simpler, same intent):
- **Segment cuts:** coast nodes grouped by the nearest of a seed-keyed point set ~1,500 km apart (fixed on the sphere, so resolution-independent). This replaces noise peaks along the coast, which would need coast nodes ordered as a 1D path on a grid (fragile).
- **Active-share steering:**
  - each seaway's "active option" is one-sided if `D` < 300 km, else closing;
  - seaways are sorted by `u / w(D)` (`u` keyed by the seaway's position, `w` grows with `D`);
  - active options are taken until the active coast length reaches `active_share`;
  - active share 0 means every seaway opens (the "all passive" preset).
- **Coasts with no axis at all** (a one-landmass world) form one "open" pseudo-seaway per landmass, treated as closing; a passive open coast claims a 1,500–2,500 km apron (its far edge becomes a ridge).
- **Sutures:** one kind per landmass for all its internal boundaries (collision 70% / rift 30%); no "old suture" merge yet.
- **Passive coast vs oceanic plate**, the lateral boundary within 400 km of the coast: prescribed transform, so no trench lands near a passive coast.

### Advisor verdict on the plan (s05)
Sound, with one blocker: **every discrete decision must come from one fixed grid**. `generate_refined` runs tectonics at 320 and at the fine res, and takes `D = T_fine − up(T_canon)`. A class flipping between the two runs would put a whole trench into `D` and break the s04 guard.
Decision: a **fixed res-128 classification grid C** (its own `crust::build`).
- On C, independent of the generation res: landmasses, regions, seaways, `D`, lengths, class rolls, segment rolls, the active side, sutures, the oceanic seed positions, **and the motion solve itself** (plates' Euler vectors come from C).
- The fine grid only samples these (nearest C node) and computes continuous geometry: distances, region borders, trench offsets.
- Plate ids are fixed by C entities: landmass sub-plates first, then oceanic seeds. Fine components that miss a seed are merged into a neighbouring plate, and empty plates are compacted away.
- Since C is bit-identical across resolutions, the plain RNG in C order is stable (no centroid-keyed noise needed).
Other points adopted:
- kinds map to the legacy classes (subduction/collision → CONVERGENT, ridge/rift → DIVERGENT);
- schema 5 now, with optional chunks;
- a plausibility probe before tests, measured against the emergent coast;
- watch the res 64/96 tests and `probe_bathymetry`.

## R3.1b (built)
- `mask.rs`: `Conditioning` (strict, mask, outside_procedural + 800 km guard, islands + 100 km guard, strokes), `RasterMask` (equirect / azimuthal-equidistant patch, bilinear), `Stroke`, `land_cover`.
- Procedural strict uses `crust::continentalness` thresholded straight to the land fraction.
- Strict crust = land + class margins: passive 150–250 km capped at 0.4·D; active = trench offset − 20 km. The base ramps from the mask coast. No bisection. Land ≥ 1 m; sea ≤ −1 m, with heights above −200 m compressed softly. Islands are optional.
- Erosion ocean = `snapshot.land_cover` sampled at erosion nodes (h0 nudged to agree). The gates (exact sign match at tectonic and eroded nodes) are tests, n = 1 seed at res 48/64.
- Lake beds on mask land: covered by the eroded-sign test, since no land sample is ≤ 0.
