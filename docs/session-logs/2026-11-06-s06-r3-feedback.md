## Built from that feedback (`a4c2f66`, `491b986`)
- **Brush:** with a brush tool on, every stroke draws in the viewport as a translucent band in the tool's colour (globe and map), and so does the stroke in progress. A geodesic ring at the brush radius plus a crosshair is the cursor. Bands are triangle strips with half-disc caps, so the caps don't double the alpha. Strokes show only while a brush tool is active.
- **Import:** an always-visible "Import coastline…" button opens a file dialog (`rfd` 0.17, native only). Dropping a .png or .svg on the window also imports it, with a hint shown while a file hovers. A 2:1 image is taken as a whole-world map; any other shape becomes a ~3,000 km regional patch at the current centre, with a message saying so.
- **`RG_SHOT_UI=1`** (with `RG_SHOT`) saves the whole window (egui `ViewportCommand::Screenshot`), panels and overlays included. `screencapture` and the cua-driver window grab both fail here (no screen-recording permission), and `RG_SHOT` alone saves only the planet render. Verified with a temporary demo-stroke hook (removed): bands and the ring are correct on the globe and the map.
- Not done: ray picking against the relief (painting uses the sea-level sphere).

## Import adjust + drag-to-place (Matt, s06): plan and advisor verdict
Matt: his coastline is greyscale, not binary. He asked for quick invert/levels/curves/crop before import, plus a way to drag a non-2:1 image across the map or globe.
- Note: greyscale already worked (brightness above 50% = land), but the cutoff was fixed and there was no preview.
- Rejected: full levels and curves panels. For a land/sea mask they collapse to a threshold.
- **Advisor (go, with changes, all adopted):**
  - Threshold and invert live in core and apply in `coverage()` after bilinear: `(v' − t) + 0.5`, so the coast sits on the threshold contour. The defaults (0.5, no invert) return `v` unchanged, so existing imports stay byte-identical. One `pub fn` is shared with the UI preview.
  - Channel override (auto / brightness / alpha). The "any alpha varies" auto rule can silently pick alpha on a greyscale export.
  - Crop at decode time, in integer source pixels. The 2:1 test runs on the cropped size.
  - Threshold, invert and crop are hidden for SVG.
  - New header fields are optional, with defaults. The round-trip test is extended. `world_hash` should stay unchanged.
  - Preview: a raw thumbnail of at most ~512 px, tinted on the CPU; the real mask is rebuilt only on release.
  - Placement: `RasterMask::dir_of_pixel` (inverse azimuthal equidistant), with a round-trip unit test as the gate. Overlay = dense outline + a coarse land tint. "Move patch" mode is exclusive with the brush. Drag rotates the centre direction (not lat/lon deltas). SVG km/px goes through `user_placement`.
  - Avoid cloning the raster every frame: the pixel data goes behind its own `Arc`, so `Arc::make_mut` on the mask is cheap.
  - Three commits; targeted tests, then the full suite.
