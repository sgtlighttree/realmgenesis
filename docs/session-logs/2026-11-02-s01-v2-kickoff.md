# 2026-11-02 · s01 · v2 kickoff

Cloud session. Matt wants v2 rebuilt from scratch as a native app: a 3D globe + 2D map, raster + vector modes, tectonics, climate, oceans, zoom-generated detail, and sculpting.

## Decisions

- **Rust + wgpu + eframe/egui.**
  - Rejected Java: no web target, GC pauses.
  - Rejected Electron/Tauri: the binary size, and a webview defeats native rendering.
  - Rejected Bevy: compile times, UI immaturity.
  - egui was chosen for iteration speed. Matt wants a polished redesign later, so the UI sits behind `Command`s.
- **Orphan branch.** Matt wanted no context pollution from V1. The lessons were copied to `docs/lineage/`.
- **Hybrid generation:** reroll until close, then shape with intent and sculpt (Matt Q1).
- **Climate is one-shot, then frozen.** Tier A runs on reroll, tier B on commit. Matt: "not long running CFD-style sims."
- **Tectonics: snapshot.** History is parked (Matt Q6).
- **Sculpting:** delta tiles at fixed internal levels, macro L4 (about 2.4 km) and local L10 (about 38 m). Macro edits mark climate stale. The zoom floor is about 10 m.
- **Geodesy:** one ellipsoid code path, default f = 0. Rejected a separate sphere/ellipsoid mode: double the code for no benefit.
- **Climate on a lat-lon 1° grid; tectonics and terrain on the cube-sphere.** Rejected cube-sphere climate: face-seam stencils, and every reference model uses lat-lon. To be reviewed by the advisor stand-in.
- **Determinism:** committed fields are stored in the world file. GPU floats aren't cross-vendor reproducible, so nothing gated depends on GPU recomputation.
- **Push and HANDOFF override (Matt):** push as often as possible, and keep HANDOFF and the session log current so a fresh session can continue.

## Findings

- **GPU probe artifact** (https://claude.ai/artifact/64fD9SPXY3zpiZh8HjAURZ), on the M1 in Vivaldi (Chrome 152):
  - WebGPU works inside the claude.ai artifact frame: Metal 3, `shader-f16`, subgroups, timestamp-query, 4 GiB storage buffers, max texture 16384.
  - A compute shader did 1M cells × 64 iterations in 4 ms.
  - `crossOriginIsolated = false`, so no SharedArrayBuffer and no Wasm threads. **Verified (n=1 device).** Implication: GPU-first simulations.
- **Climate research:** `docs/research/2026-11-02-climate-tier-b.md`. Closest prior art: raguilar011095/planet_heightmap_generation (1°, 12 months in seconds, in JS). Licences unverified, so we reimplement from docs and don't copy code.
- **Container:** Rust 1.97 present, 4 cores, 15 GB RAM. trunk installed via cargo.
- **mediasheet-for-obs has no session logs on GitHub** (public repo, main only). The style reference must come from Matt.
- **No advisor tool and no Context7 in cloud sessions.** Substitutes: a fresh-context reviewer agent, and `cargo search` / docs.rs.
