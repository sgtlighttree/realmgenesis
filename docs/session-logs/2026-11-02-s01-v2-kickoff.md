# 2026-11-02 · s01 · v2 kickoff

Cloud session. Matt wants v2 rebuilt from scratch as a native app: a 3D globe + 2D map, raster + vector modes, tectonics, climate, oceans, zoom-generated detail, and sculpting.

## Decisions

- **Rust + wgpu + eframe/egui.**
  - Rejected Java: no web target, GC pauses.
  - Rejected Electron/Tauri: the binary size, and a webview defeats native rendering.
  - Rejected Bevy: compile times, UI immaturity.
  - egui was chosen for iteration speed. Matt wants a polished redesign later, so the UI sits behind `Command`s.
- **Orphan branch.** Matt wanted no context pollution from V1. The lessons were copied to `docs/lineage/`.
- **Hybrid generation:** reroll until close, then shape with intent and sculpt (Matt Q1).
- **Climate is one-shot, then frozen.** Tier A runs on reroll, tier B on commit. Matt: "not long running CFD-style sims."
- **Tectonics: snapshot.** History is parked (Matt Q6).
- **Sculpting:** delta tiles at fixed internal levels, macro L4 (about 2.4 km) and local L10 (about 38 m). Macro edits mark climate stale. The zoom floor is about 10 m.
- **Geodesy:** one ellipsoid code path, default f = 0. Rejected a separate sphere/ellipsoid mode: double the code for no benefit.
- **Climate on a lat-lon 1° grid; tectonics and terrain on the cube-sphere.** Rejected cube-sphere climate: face-seam stencils, and every reference model uses lat-lon. To be reviewed by the advisor stand-in.
- **Determinism:** committed fields are stored in the world file. GPU floats aren't cross-vendor reproducible, so nothing gated depends on GPU recomputation.
- **Push and HANDOFF override (Matt):** push as often as possible, and keep HANDOFF and the session log current so a fresh session can continue.

## Advisor-stand-in review of ARCHITECTURE (fresh-context Plan agent, s01)

Verdict: sound, but fix these before scaffolding. **All adopted**, and ARCHITECTURE.md is revised:

1. **f32 noise breaks at L10–L12.** WGSL has no f64, and a unit-sphere f32 has about 0.4 m spacing. Fix: integer lattice coordinates from the tile address + an f32 fraction for high octaves.
2. **Tile layout pinned:** 257² corner-aligned vertices + skirt. Tangent warp, id 1, stored in the file.
3. **Committed macro at L3, not L4.** L4 dense is about 100M samples, roughly 400 MB f32 per field. L4 stays the edit level as sparse deltas. Tectonics on a 10k–100k graph. Hydrology on L2–L3.
4. **Sims are stepped `Job`s.** Web readback is async, and the GPU watchdog kills long dispatches. Chunks stay under 100 ms. This has to be in from M1, or it means a rewrite.
5. **Detail is constrained by the committed coast SDF and rivers,** so the coastline never moves when zooming.
6. **Sculpt deltas:** a downsampled pyramid up to about L6, plus `detail_generator_version` with old versions kept callable.
7. eframe kept; render-to-texture with reversed-Z Depth32Float. The wgpu version is pinned to egui-wgpu's.
8. **World file + golden tests moved to M2** (they were at M8).
9. 2D mode moved to M3. A frame-time HUD in M0.
10. New crates: `rg-gpu` and `rg-pipeline`. `rg-world` holds types and serialization only. WGSL is composed by plain concatenation.
11. Climate downscaling at display time (lapse rate, orographic term).
12. `f` is locked at generation.

- **Climate agent caveat:** hess.copernicus.org was blocked for it, so its Köppen rules and test station normals come from memory. Unverified against Peel 2007 Table A1. Re-check when the network allows.
- **Layer architecture:** every layer is an equirect RGBA texture baked on the CPU. The globe samples it by lat/lon in the fragment shader; the 2D map is a fullscreen pass with hillshade from an R32F height texture (textureLoad + manual bilinear, since R32F isn't filterable everywhere).
- **Downscaling:** per pixel, interpolate monthly T/P, apply the lapse rate for fine-minus-coarse height, re-classify Köppen. Coasts and ranges come out sharp; the 1° grid still shows as blocky zonal edges.
- **Footgun (verified):** serde_json's default f64 parsing doesn't round-trip exactly (last-digit differences in plate poles). The `float_roundtrip` feature is required for byte-identical save → load → save.
- **Footgun:** never `assert_eq!` multi-megabyte Vecs in tests. It printed 64 MB of output.
- **sRGB:** palettes are authored as sRGB bytes into an `Rgba8UnormSrgb` texture, so they're dark in linear space, and lighting multiplied them darker still. Fixed with wrapped diffuse and about 1.45 exposure in `fs_globe`.
- **CI:** run 4 failed because the intermediate tectonics commit referenced the old `GlobeRenderer` (expected). Run 5 is on the MVP commit.
- **CI green** on 496a464 after pinning 1.97.0 and switching to `as_chunks` (clippy 1.99's `chunks_exact_to_as_chunks` lint). Native binaries for macOS arm64, Windows and Linux are uploaded as run artifacts.

## Terrain realism (s01)

- **Matt (2026-11-02):** "The elevation maps don't feel quite realistic, they don't follow typical erosion and IRL terrain." Ultra runs well on the M1 (mobile not tested). Custom wouldn't go below 10 km.
- **Cause of the 10 km floor:** the s01 cap at res 1024. **Decision:** native cap raised to 2048 (~5 km cells; est. ~4 GB peak, untested above 1024) with a GB readout that turns amber above 2 GB. The web stays at 1024 (wasm32 4 GB limit).
- **V1 lineage:** V1 ran hydraulic + thermal erosion per Voronoi cell, then a Priority-Flood river solve. Its 2026-07-25 research recommended simple graph diffusion.
- **Deep research launched (Haiku, Matt's request):** FOSS erosion and terrain algorithms. The brief targets a two-stage design: (A) macro stream-power erosion + drainage on the committed cube-sphere grid at generation; (B) per-point analytical erosion detail conditioned on macro drainage, so tiles stay pure functions.
- **Matt's /goal: "very realistic, mathematically and scientifically accurate terrain".** Full write-up: `docs/design/terrain-model.md`. Highlights:
  - **Stage A** `rg-erosion`: Braun–Willett SPL + Priority-Flood on the sphere graph. **Verified:** uplift-normalised concavity 0.4500 = m (the analytic steady state); Hack h 0.54; 100% drained.
  - **Hypsometric calibration** (monotonic quantile map onto Earth's curve) replaced the p99 rescale, which gave about 2× Earth heights. Now mean 841 m vs 840.
  - **Stage B:** Johansen's erosion filter as an MPL-2.0 port in its own file, generalised to 3D. **Licence correction:** bevy_erosion_filter is MPL-2.0, not MIT as the research agent said.
  - **Detail realism measured against Earth:** 90 m slopes in mountain belts average 15–20°; plains 0.6°.
  - **Eleven artifact classes** found with probes, all fixed. Table in the design doc.
  - **Refuted hypothesis (worth remembering):** I spent several iterations sure the arcs/X-trenches came from the gully filter. They survived every filter change because they came from the base surface: ridged-noise zero-contours and valley kinks. **Lesson: when an artifact survives a rewrite of a component, it isn't in that component.** Bisect by component (`probe_grid`) before theorising.
  - **CDLOD geomorph:** vertices store the parent mesh surface (even vertices = parent heights; odd = edge or a–d diagonal averages); the shader morphs by projected cell size (lod uniform). The gully slope uses fixed 250 m finite differences, so every LOD sees the same slope and parent heights match exactly.
  - **Probes for future tuning:** `RG_HILL_SLOPE` / `RG_GULLY_STRENGTH` env overrides (native only); `rg-pipeline` examples `probe_line`, `probe_grid`, `probe_slope`, `probe_hypsometry`, `find_peaks`.
- **Advisor-stand-in review of the terrain model: "not yet defensible as Earth-accurate".** Ranked:
  1. **Detail ignores drainage between 4 and 60 km.** A flat hill spectrum of about 0.95 km per octave, as large as the macro valleys. Fix: band-limit the hills, carve the macro rivers, and later a per-tile refinement solve.
  2. **The hypsometry remap is at the wrong scale.** A 1.8 km DEM curve (with ice sheets) imposed on 20 km cells; ranks not area-weighted; validation done before detail. It also breaks S = U/K·A^m.
  3. **The concavity check is near-identity.** Need real solver tests: area conservation, mass balance, an analytic 1-D profile and knickpoint celerity, dt convergence.
  4. **Uplift ∝ elevation is circular.** Should come from tectonic process (distance to convergent boundaries).
  5. **Filling every pit:** no endorheic basins (Earth has about 18–20% of land draining internally) and no deposition (Yuan 2019).
  6. **Slope claims overstated.** Threshold landscapes peak near 30–35° with narrow distributions; compare full histograms and spectra.
  7. **Pit metric is wrong.** Use Priority-Flood fill area and depth instead.
  8. **Missing regimes:** glacial, arid, coasts.
- **Acting on it:** items 2–4 go to a Sonnet agent (rg-erosion); items 1 and 7 plus re-validation I do myself; 5 and 8 are logged as the next science steps.
- **Drainage consistency measured** (`examples/probe_drainage.rs`: Priority-Flood fill on a 500 m grid with the box edge as outlet, plus D8 agreement with the macro flow on river cells). Shipped detail (hills + gullies): **10–14% of land in closed depressions, mean depth 145 m**; flow agreement 52–60% (random ≈ 33%). The old "pit fraction" metric (0.2%) hid this. **The reviewer was right.**
- **Bisection:**

  | Configuration | Depressions | Mean depth | Flow agreement | Mountain mean slope |
  |---|---|---|---|---|
  | Macro only | 0–0.9% | — | 72–81% | — |
  | Gullies on macro | 0.02–1.2% | 2–30 m | 76–78% | 3–7° (too gentle) |
  | Hills alone | 2.5–3.9% | 31 m | — | — |
  | Hills + gullies | 10–14% | 145 m | 52–60% | 11–24° |

  The filter is drainage-consistent only while its along-flow slope stays below the base slope. Gullies with a large first wavelength (16 km) gave up to 25% depressions.
- **Principle (verified):** stateless detail can be steep or drained, not both. The 5–30 km steepness must come from a routed physical solve.
- **Plan:**
  1. Decouple erosion resolution from tectonics resolution (tectonics 320, erosion 768–1024, committed macro at erosion resolution), with fewer steps (they converged by 50).
  2. Detail becomes small, drained perturbations (gullies, little or no hills).
  3. Re-validate the FINAL surface: depressions under 1%, flow agreement ≥ 75%, mountain slopes, hypsometry.
- An Ultra run with erosion at 1024 took 60 s (tectonics 21 s + erosion 38 s); too slow as-is.
- **River corridors** (flatten detail and cut the channel along macro rivers with area ≥ 3000 km²) and the band-pass hill spectrum are committed. `terrain_sampler(world)` is now the one way to build the sampler (app, tests and probes share it).
- **Erosion res decoupled** (`ErosionParams::res`; 0 = tectonics res capped at `max_res`). The world file stores `snapshot.height_res` and the four uplift params. Timings, seed 3, tectonics 320: erosion 768 × 20 steps 13 s, 768 × 50 steps 24 s, 1024 × 20 steps 29 s.
- **New probe `probe_realism`:** generates once (cached in `target/probe-cache/`), scores 3 rugged boxes + 1 lowland on the FINAL surface. `RG_PROBE_SURFACE=macro` scores the bare macro.
- **Finding: the bare macro surface was damming itself.** Bilinear interpolation of a D8-drained field: a diagonal valley gets the two ridge corners averaged in mid-cell. Up to 9.5% of mountain land in closed depressions, 150 m deep, with hills and gullies OFF.
- **Fix, with proof:** `CubeField::sample_drained` splits each cell along the diagonal through its lowest corner. If d drains diagonally to a, then a is below both other corners (else the shorter, steeper axis neighbour wins D8), so every drainage edge is a triangle edge; a piecewise-linear surface has minima only at vertices. **Macro depressions: 9.5% → 0.04%.**
- **The "flow agreement" metric is flawed:** it counts every point where the bilinear drainage exceeds 3000 km², i.e. the valley sides too. Replacing it with thalweg checks along the actual river edges.
- **Matt's feedback (screenshot):** some rivers are dead straight and parallel (D8 on smooth tilted surfaces: needs a rough initial surface and/or stochastic slope-weighted routing); zoomed-in mountains are "a bit swirly" (Phacelle steering) "but they do feel natural now". **Goal extended: bathymetry** (age–depth law, shelf/slope/rise, trenches, ocean hypsometry).
- **Straight parallel rivers (Matt's screenshot), measured:** `probe_realism` now reports channel straightness (share of steps on > 1000 km² channels that keep the exact flow direction; longest straight run) and `river_map` renders hillshade + network to PNG. Seed 3, erosion 768: **65% straight, longest run 104 cells (~1,300 km)**.
  - Hypothesis "Priority-Flood+ε flats draw the combs" **refuted**: flats 20% straight, slopes 55%.
  - **Rho8 routing** (Fairfield & Leymarie 1991: diagonal effective length random in [1, 2] instead of √2, seeded per node). Never below 1, so `sample_drained`'s proof still holds. **Initial roughness** (20 m white, Braun & Willett start from noise). Together: **48% straight**. `river_map` before/after shows the combs and 45° ruler trunks mostly gone.
  - **Lithology** (log-normal K, σ_lnK, 250 km correlation): no effect on straightness (63% alone). At σ 0.6, basin HI fell to 0.20 and Hack h rose to 0.64; at **σ 0.3** the laws hold (Hack 0.59–0.60, HI 0.24–0.36). Default 0.3.
  - The uplift-normalised concavity stat now divides out U/K (steady state S = (U/K)·A^-m), not just U: back to exactly 0.450.
- **Remaining grid feel** comes from rivers drawn/carved as straight node-to-node segments. Next: smooth river curves (map layer + 3D corridor).
- **Visual check caught a regression I'd pushed:** the triangle-split interpolant drew facets and creases in the hillshade (gully steering and relief read piecewise-constant slopes). **Replaced** by `drained_interp`: bilinear minus `e·fx·fy(1−fx)(1−fy)/(t(1−t))` along the diagonal through the lowest corner (e = b+c−a−d > 0). It equals the bilinear dam exactly on the diagonal, is zero on the cell edges, and is smooth. It isn't a strict guarantee (the thalweg can drift off the diagonal when b ≠ c): bare-macro depressions are 0.05–3% vs 9.5% bilinear and 0.05% triangles. Facets gone.
- **Cell-edge crease lines** came from gully steering by a 250 m slope that flips at the macro's C0 edges. Steering now uses a 3 km central difference: lines gone, gully networks read dendritic. **Remaining:** square tonal blocks (the macro's own shading jump at cell edges); needs a C1 drained macro.
- **Hills off by default** (HILL_SLOPE 0): they put 13–16% of mountain land in closed depressions. Gully sweeps confirm the steep-or-drained trade-off (SLOPE_GAIN 0.5: 0.5–2% depressions but 7–10° slopes).
- **Reviewer (advisor stand-in) verdict:** "No-depression result holds, but for a different reason than claimed." Acted on:
  1. Presets above 512 voided the guarantee (delta upsample): erosion now runs at the preset res (max_res 2048), and the upsample branch is PF-filled on the fine grid.
  2. The Rho8 lemma was wrong on warped cells (1:√2 rectangles). The real argument: axis edges are always cell edges, so a lower diagonal is the cell's unique minimum. Docs fixed.
  3. Rho8 diagonals by **topology** (`diagonal_mask`: axis pairs share 4 neighbours, diagonals 2) instead of a length test. Test added.
  4. Remap `.max(1.0)` ties: now strictly increasing as stored f32 (`next_up`).
  5. Roughness scaled by local relief (≤ 0.25 × max neighbour difference), so plains don't become ε-flats.
  6. Schema 3: `macro_interp` id, erosion `seed` stored, legacy `uplift_source` defaults to Tectonic.
  7. Layers and hover readout use `sample_drained`.
  - **Not yet:** lithology tied to crust/terranes; χ-analysis instead of the circular U/K concavity; validating the remapped (shipped) surface.
- **Steps 50 → 20:** same laws at res 320 (Hack 0.58/0.58, θ 0.53/0.53, basin HI 0.32/0.33), half the time.
- **Scorecard on the new defaults (seed 3):** res 320: depressions 0.1–1.2%, slopes 6–9°; res 768: 1.7–5%, 14–17°, p99 55°.
- **Decision:** next is Dendry-style network detail (Gaillard et al. 2019), drained by construction with SPL channel profiles. Then bathymetry (Matt's addition).
